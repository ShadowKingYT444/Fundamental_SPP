# Fundamental_SPP — paper reproduction

End-to-end reproduction of "Fundamental Information for Low-Turnover Equity ML"
(Mamba-inspired state-space model for long-horizon stock trading).

`src/` holds the data pipeline, models (MISS, LSTM, StockMixer, GNN),
walk-forward sweep driver, backtester, and evaluation code. See `SPEC.md`
for the reproduction plan and `REPORT.md` (forthcoming) for verified results.
